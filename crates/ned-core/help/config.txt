After a successful edit, each changed file is formatted, and the formatter's
changes are shown under `fmt NAME`. Missing formatters are skipped with a
note, or the language server formats the file if a daemon is running.
Defaults: rustfmt, gofmt, ruff (then black), prettier (JS, TS, Markdown).
Override them per language in .ned.toml (any directory above the file; nearer
wins) or ~/.config/ned/config.toml:

  [format]
  rust = ["rustfmt", "--edition", "{edition}"]
  python = false

{path} is the file's absolute path; {edition} comes from Cargo.toml.
--no-fmt skips formatting.

Language servers (for daemon features) are set the same way, under [lsp]:
rust-analyzer, gopls, pyright-langserver, typescript-language-server by
default. [lsp] timeout = SECS (default 30) bounds each wait for a server.
[daemon] idle_timeout = SECS (default 600). [check] show = LEVEL sets check's
default level (warning); [check] block = LEVEL (default error) or false sets
which introduced diagnostics reject an edit. An [lsp] server can be false.

Themes colour output on 256-colour and truecolor terminals. The user config
sets one (default "default-dark"): theme = "default-light" (or a name
under ~/.config/ned/themes/, or a .toml path), or a table that changes one;
NED_THEME=NAME overrides it:

  [theme]
  from = "default-dark"
  added = "#98c379"
  [theme.syntax]
  "function.method" = "#61afef bold"
  [theme.ui]
  hunk-header = "#56b6c2"

Syntax keys are capture names (function.method falls back to function); ui
keys: header, line-number, kind, dim, hunk-header, error, warning, info, note.
