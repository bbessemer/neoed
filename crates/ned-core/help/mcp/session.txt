session

The server records every call in a session of its workspace: its script,
files and outcome, and each file it wrote, before and after. The session is
the one the server was started with, or a new mcp-N; `cd` to another
workspace moves to a session there.

`history` lists the last 10 calls (`all`: every one), a line each: the
call's number, its outcome (ok, dry run, exit N, undo N, write), how many
files it wrote, `undone` if it has been, and the script's first line:

  3 ok, 1 file: replace fn:parse>"end" with "end of input"

`undo` reverts the last call that wrote files and isn't undone, removing
files it created, and prints the diff; repeat it to go further back. A file
changed since is refused; `force` merges the undo into it instead, unless
a later change overlaps the call's.

`commit` commits just the edits written to git (all since the session's last
commit); nothing else goes in, hooks don't run, and an edit overlapping
uncommitted changes is refused.

A `ned` script of `!!` repeats the last script that edited or failed, on
its files or workspace unless others are given, but not its other arguments:
after a dry run it needs `dry_run`. `:s/OLD/NEW/` corrects the first OLD in
it and `:gs/OLD/NEW/` every one:

  !!:s/fn:prase/fn:parse/
