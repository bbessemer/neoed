text

TEXT is a string, "..." on one line, or a heredoc:
  <<END      body on the following lines, up to a line that is just END.
             Re-based: its common indentation is stripped, and each level
             becomes one indent unit of the file (tabs or spaces).
  <<'END'    verbatim.
A heredoc reads no escapes: `\x27` stays four characters, so pass a script
that holds a ' on stdin (ned FILE <<'EOF') rather than escaping it into -e.
Line-oriented text (for whole-line spans) gets a final newline and is
indented to the target: the span's first line for replace/before/after (its
last line after a literal or regex), the first line inside the span for
start/end (one unit in, if the body is blank). Several heredocs on one line
take their bodies in order. Write the text at column 0; ned indents it.
