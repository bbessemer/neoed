session

  ned -s NAME [FILE...] -e SCRIPT    (or NED_SESSION=NAME)
  ned history [-s NAME] [-w DIR] [--all]
  ned undo [-s NAME] [-w DIR] [--force]
  ned session list [--all] | delete NAME... [-w DIR]

A session records each invocation in the workspace: its script, files and
outcome, and each file it wrote, before and after. -s overrides NED_SESSION;
a name is letters, digits, `.`, `_` and `-`, not starting with `.`. Sessions
live in $XDG_STATE_HOME/ned/sessions (default ~/.local/state). A run with
-w DIR is recorded in DIR's sessions: give history, undo, `!!` or delete
-w DIR too.

`ned history` prints the last 10 entries (--all: every one), a line each:
the entry's number, its outcome (ok, dry run, exit N, or undo N), how many
files it wrote, `undone` if it has been, and the script's first line:

  3 ok, 1 file: replace fn:parse>"end" with "end of input"

`ned undo` reverts the last entry that wrote files and isn't undone, removing
files it created, and prints the diff; repeat it to go further back. A file
changed since is refused; --force merges the undo into it instead, unless
a later change overlaps the entry's.

--commit MSG commits just the edits written to git (in a session, all since
its last commit); nothing else goes in, hooks don't run, and an edit
overlapping uncommitted changes is refused.

A script that is `!!` repeats the last script, on its files or -w workspace
unless others are given, but not its flags: after a dry run it needs -n.
`:s/OLD/NEW/` corrects the first OLD in it and `:gs/OLD/NEW/` every one:

  ned -e '!!:s/fn:prase/fn:parse/'
