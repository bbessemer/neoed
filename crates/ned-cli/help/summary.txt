ned: a line editor for coding agents. A script is one transaction: every edit
applies, or none does. Output is a per-file summary plus diff hunks.

  ned [FLAGS] [FILE...] -e SCRIPT     (or the script on stdin)
  ned help [TOPIC]

Commands, separated by newlines or `;`:
  show [SEL [+N]]               print the lines of SEL, numbered, N around
  outline [SEL]                 list syntax items as pasteable selectors
  replace SEL with TEXT
  insert before|after|start|end SEL TEXT
  delete SEL
  sub [SEL] /re/ with TEXT      regex replace inside SEL; $1 ${name} $0
  move SEL before|after|start|end DEST
  file PATH...                  set the files later commands act on; globs ok
  create PATH TEXT              make a new file; later commands can edit it

Selectors (a selector must match exactly one span unless prefixed with `all`):
  12  12-20  12-$  $            lines
  /re/i  "text"  <<END          regex, literal, whole-line block
  fn:parse  impl:Parser  fn:test_*    syntax items, kind:name
  impl:Parser>fn:new            nest: search inside the previous step
  fn:parse.body                 parts: .body .sig .params .name .doc .lines
  file:src/a.rs>fn:new          scope to one file
  query{(call_expression) @sel} raw tree-sitter query
  /^## 6/../^## 7/  fn:a..fn:c  range: a match to the end of the next

TEXT is "a string" or a heredoc: <<END ... END is re-indented to fit its
target; <<'END' is inserted verbatim. Selectors resolve against the original
text, so line numbers from `show` stay valid for the whole script.

Flags: -n dry run   -q summaries only   --force skip the syntax-error guard
       --no-fmt   --lang LANG   --context N

Examples:
    replace fn:parse>"unexpected end" with "end of input"
    delete fn:debug_dump
    insert end impl:Parser <<END
    fn peek(&self) -> Option<char> {
        self.src[self.pos..].chars().next()
    }
    END
