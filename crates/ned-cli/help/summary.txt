ned: a line editor for coding agents. A script is one transaction: every edit
applies, or none does. Output is a per-file summary plus diff hunks.

  ned [FLAGS] [FILE... | -w [DIR]] -e SCRIPT   (or the script on stdin)
  ned help [TOPIC]
  ned daemon start|status|stop [DIR]           (the language-server daemon)

Commands, separated by newlines or `;`; `|` starts a new stage that sees the
edits before it (it binds looser than `;`: `a; b | c` is a;b then c):
  show [SEL [+N]]               print the lines of SEL, numbered, N around
  outline [SEL]                 list syntax items as pasteable selectors
  check [SEL] [LEVEL]           language-server diagnostics; LEVEL error..hint
  allow errors|warnings         apply edits even if they introduce errors
  replace SEL with TEXT
  insert before|after|start|end SEL TEXT
  delete SEL
  sub [SEL] /re/ with TEXT      regex replace inside SEL; $1 ${name} $0
  move SEL before|after|start|end DEST
  rename SEL to NAME            rename a symbol everywhere, via its language server
  file PATH...                  set the files later commands act on; globs ok
  create PATH TEXT              make a new file; later commands can edit it

Selectors (a selector must match exactly one span unless prefixed with `all`):
  12  12-20  12-$  $            lines
  /re/i  "text"  <<END          regex, literal, whole-line block
  fn:parse  impl:Parser  fn:test_*    syntax items, kind:name
  impl:Parser>fn:new            nest: search inside the previous step
  fn:parse.body                 parts: .body .sig .params .name .doc .whole
  const:C.value                 .attrs .ret .type .value .lines (each line)
  all fn  impl:P>fn             a kind alone is kind:*
  fn[.doc == ""]  fn[.len > 50]   filter: keep the spans where it holds
  all fn:parse.refs  "f(".def    uses and definition, via the language server
  file:src/a.rs>fn:new          scope to one file
  query{(call_expression) @sel} raw tree-sitter query
  `foo(@a, @rest...)`           syntax pattern: code with placeholders
  /^## 6/../^## 7/  fn:a..fn:c  range: whole lines, a match to the next

TEXT is "a string" or a heredoc: <<END ... END is re-indented to fit its
target; <<'END' is inserted verbatim. Selectors resolve against the text at
the start of their stage, so line numbers from `show` stay valid until the
next `|`. After a `|`, check, rename, .refs and .def are errors.

Flags: -n dry run   -q summaries only   --force skip the guards (syntax, check)
       --no-fmt   --no-check   --lang LANG   --context N
       -w [DIR] every file in the workspace (.gitignore respected)

Examples:
    replace fn:parse>"unexpected end" with "end of input"
    delete fn:debug_dump
    insert end impl:Parser <<END
    fn peek(&self) -> Option<char> {
        self.src[self.pos..].chars().next()
    }
    END
