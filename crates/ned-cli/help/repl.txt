repl

  ned repl [FILE... | -w [DIR]] [-s NAME] [--attach NAME]
  ned [FILE... | -w [DIR]]           (on a terminal, without -e)

An editor for humans. Each line is a script, run on the file set as `ned`
runs it, but edits go to in-memory buffers until written. Output, the
syntax guard, formatting and edit checks are as for `ned`; :write also
reports what checks run on save (cargo check) find the write introduced.
A script that ends inside a heredoc or pattern continues on the next line.
`!!` repeats the session's last script.

Commands (any unambiguous prefix works: :w, :u, :q):
  :write [FILE...]    write unwritten edits, merging into files changed since
  :write! [FILE...]   write them as they are, without merging
  :commit MSG         write, then commit the session's edits since its last
                      commit (as --commit does), and nothing else
  :undo               undo the last script's edits; repeat to go further back
  :diff [FILE...]     what :write would write to the files on disk
  :reload [FILE...]   drop unwritten edits
  :files [FILE... | -w]   print, or replace, the file set
  :history [--all]    the session's history
  :attach NAME        follow session NAME (an agent's) and record into it
  :detach             stop following
  :help [TOPIC]       ned help TOPIC
  :quit  :quit!  :wq  quit; discard unwritten edits; write, then quit

It records into a session: -s NAME, NED_SESSION, or a new repl-N. Each
script is recorded, and each :write as a `write` entry that `ned undo` reverts.
Attached, it prints each entry the agent records, with its diff.
