check [SEL] [LEVEL]

Prints the language server's diagnostics for each file in the set, or those
overlapping SEL, at LEVEL or above: error, warning, info or hint (default
`[check] show`, which is warning unless configured). Diagnostics are for the
file as it was before the script. Starts the per-workspace daemon and the
server if needed, and waits for indexing (`[check] timeout`, default 30s).
Files without a server are skipped.

  src/parser.rs:15:9: error: mismatched types [rust-analyzer E0308]

Examples:
    check
    check fn:parse
    check impl:Parser hint
