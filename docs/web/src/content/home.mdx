## Refactoring by hand

These examples run on a small Rust crate, and the output is real. The
[tutorial](/tutorial) walks through everything step by step.

<Example>

### Every outline line is a selector

Paste any of them into a command.

```ned
$ ned src/parser.rs -e outline
```

```text

  19-22 fn:parse
  24-30 fn:parse_expr

  52-54 fn:fmt
```

### Ambiguity is an error, with the fix

ned never guesses which match you meant.

```ned
$ ned 'src/*.rs' -e 'show fn:new'
```

```text
error: script:1:6: fn:new matches 3 items; add `all` or use one of:
  impl:Lexer>fn:new    src/lexer.rs:14-19
  impl:Parser>fn:new   src/parser.rs:12-17
  impl:Error>fn:new    src/parser.rs:46-48
```

</Example>

### Write code at column 0

ned indents it to fit.

```ned
$ ned src/lexer.rs <<'EOF'
insert end impl:Lexer <<END

fn peek(&self) -> Option<char> {
    self.chars.get(self.pos).copied()
}
END
EOF
```

```diff
src/lexer.rs: 1 edit, +4 -0
@@ -31,2 +31,6 @@
     }
+
+    fn peek(&self) -> Option<char> {
+        self.chars.get(self.pos).copied()
+    }
 }
```

</Example>

### Match code by writing it

Placeholders capture what varies, whatever the spacing.

```ned
$ ned src/parser.rs -e 'replace all `assert_eq!(@a..., true)` with "assert!(@a)"'
```

```diff
src/parser.rs: 2 edits, +2 -2
@@ -63,3 +63,3 @@
         let mut p = Parser::new("42");
-        assert_eq!(p.parse().is_ok(), true);
+        assert!(p.parse().is_ok());
     }
@@ -69,3 +69,3 @@
         let mut p = Parser::new("");
-        assert_eq!(p.parse().is_err(), true);
+        assert!(p.parse().is_err());
     }
```

</Example>

<Example>

### Restructure in one transaction

Every command applies, or none does. Then your formatter runs.

```ned
$ ned 'src/*.rs' -q <<'EOF'
create src/error.rs <<END
use std::fmt;

END
move struct:Error..impl:"Display for Error" end file:src/error.rs
delete file:src/parser.rs>import:std::fmt
insert after import:crate::lexer* "use crate::error::Error;"
insert before "mod lexer;" "mod error;"
EOF
```

```text
src/main.rs: 1 edit, +1 -0
src/parser.rs: 3 edits, +1 -17
fmt rustfmt: +1 -1
src/error.rs: created, +16
```

</Example>

## Using ned with AI agents

Agents pay for every token. ned's commands are short, its diff replaces reading
the file back, and its errors say how to fix them. Here's what common edits
cost, in tokens:

| Task                            | ned | Python | search and replace |
| ------------------------------- | --: | -----: | -----------------: |
| Change a string in one function |  22 |     61 |                 32 |
| Add a method to an impl         |  41 |     94 |                 74 |
| Delete a function               |  13 |     70 |                 44 |
| Replace a function body         |  38 |     93 |                 62 |

For Claude Code, install the skill:

```sh
git clone https://github.com/bbessemer/neoed
cp -r neoed/docs/skills/ned ~/.claude/skills/
```

For other agents, the
[agent guide](https://github.com/bbessemer/neoed/blob/main/docs/agent-guide.md)
has a short system-prompt snippet.
